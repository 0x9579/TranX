TranX 隐私政策

最后更新日期：2026-07-26
产品名称：TranX — X 悬浮词典
适用范围：TranX 浏览器扩展（Chrome / 兼容的 Chromium 浏览器）

本页为 Chrome 网上应用店等渠道所需的公开隐私政策。扩展安装包内不依赖本页面即可运行。

1. 概述

TranX（下称「本扩展」）帮助你在 X（Twitter）网页上查看外语文本的中文释义或翻译，并可收藏英语单词到本地生词本。

我们重视隐私。本扩展：

  • 不要求注册 TranX 账号
  • 不运营面向用户的自有账号服务器来存储你的生词（当前版本）
  • 不会出售你的个人数据
  • 不会将你的浏览历史用于广告画像

2. 我们处理哪些数据

2.1 保存在你设备上的数据（浏览器存储）

数据 存储位置 用途
偏好设置（如是否启用、悬浮延迟、取词语言等） chrome.storage.sync 或本地存储（依浏览器实现） 记住你的选项；若开启了浏览器账号同步，设置可能随浏览器账号在设备间同步
英语生词本 chrome.storage.sync（每词一个键） 仅保存英语词形与收藏时间；可经浏览器账号跨设备同步；不保存释义正文
查词缓存 chrome.storage.local 加快重复查询；可在设置中清除，不影响生词本

你可随时通过扩展弹窗删除生词、清空生词本或清除查词缓存；也可卸载扩展以删除其本地数据（以浏览器行为为准）。

2.2 为提供查词/翻译而发送的数据

当你在页面上悬停或触发查词/翻译时，本扩展的后台脚本会向第三方词典或翻译服务发送：

  • 当前查询的英语单词，或
  • 日语/韩语场景下的一行文本（整行翻译）

可能用到的服务域名包括（以扩展 manifest 中的 host_permissions 为准）：

  • dict.youdao.com（有道词典相关接口）
  • api.dictionaryapi.dev（英语词典接口，主要用于音标/英文释义补充）
  • api.mymemory.translated.net（机器翻译，用于整行或兜底）

这些请求用于返回释义或译文。第三方如何处理请求数据，受其各自隐私政策约束，本扩展开发者无法完全控制。

2.3 我们不主动收集的数据

本扩展不会故意收集或上传：

  • 你的 X / Twitter 账号密码
  • 完整的页面浏览历史列表
  • 通讯录、精确地理位置
  • 支付信息

内容脚本仅在 x.com / twitter.com（及清单中声明的移动/www 子域）上运行，用于识别指针下的文本并显示提示层。

3. 权限说明（摘要）

权限 原因
storage 保存设置、生词本与查词缓存
访问 X/Twitter 页面 在帖子文本上提供悬停查词 UI
访问词典/翻译域名 代为请求释义与翻译（避免页面跨域限制）

4. 数据是否离开你的设备

类型 是否离开设备
设置、生词本 使用 chrome.storage.sync 时，可能经 Chrome/Google 同步服务在你已登录的设备间传递，而非本扩展自建服务器
查词缓存 仅本机 local，不同步
查词/翻译请求中的词句 会发送至上文所述第三方服务

当前版本没有TranX 自有后端用于上传你的生词本。

5. 数据共享

除下列情形外，我们不会出售或出租你的个人数据：

  1. 提供功能所必需：向词典/翻译服务发送查询词句；
  2. 法律要求：在适用法律要求或为保护权利与安全时；
  3. 你明确选择的操作：例如你自行使用「导出」功能把生词本保存为文件并分享给他人。

6. 数据安全

我们采取合理的技术措施（如使用浏览器扩展隔离环境、限制匹配站点）降低滥用风险。但任何网络传输与第三方服务都无法保证绝对安全，请你理解剩余风险。

7. 儿童隐私

本扩展不面向 13 岁以下（或你所在司法辖区规定的更高年龄）儿童。若你认为儿童向本扩展相关服务提交了信息，请联系我们以便处理。

8. 你的选择

  • 在扩展内关闭功能、清除缓存、删除或清空生词本
  • 使用浏览器提供的站点权限与扩展卸载功能
  • 通过导出功能备份生词本后自行保管文件

9. 政策变更

我们可能更新本政策。更新后将修改文首「最后更新日期」，并在可行时通过扩展商店说明或项目页面提示。重大变更后继续使用，即表示你了解更新后的政策（在适用法律允许的范围内）。
