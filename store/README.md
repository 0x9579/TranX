# store/ — Chrome 网上应用店材料

本目录存放**上架与审核**相关材料，与扩展运行时无关。

- **不要**把本目录打进扩展安装包（zip / crx）
- 开发加载扩展时，请选择仓库中的 `extension/`，而不是本目录

## 计划中的文件

| 路径 | 用途 | 状态 |
|------|------|------|
| `LISTING.md` | 商店名称、简介、详细描述 | 待写 |
| `PRIVACY.md` | 隐私政策正文（需再托管为公网 URL） | 待写 |
| `PERMISSIONS.md` | 权限与 host 用途说明（对照审核） | 待写 |
| `CHECKLIST.md` | 开发者注册与提交流程清单 | 待写 |
| `assets/` | 商店截图、宣传图 | 空目录 |

扩展图标仍放在 `extension/icons/`；商店要求的大尺寸宣传图放 `assets/`。
