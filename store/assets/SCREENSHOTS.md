# 商店截图拍摄指南

将成品图放在本目录（`store/assets/`）。  
**不要**把大尺寸宣传图放进 `extension/`，以免增大安装包。

---

## 建议规格

以 [Chrome Web Store](https://developer.chrome.com/docs/webstore/images) 当前文档为准，常见要求：

| 项目 | 建议 |
|------|------|
| 截图 | **1280×800**（优先）或 640×400 |
| 格式 | PNG 或 JPEG |
| 数量 | 至少 1 张，建议 **4–5** 张 |
| 内容 | 真实扩展 UI，避免误导性伪造数据 |

---

## 建议拍摄清单

在浅色或深色 X 界面均可，保持可读。

| 序号 | 文件名建议 | 画面内容 |
|------|------------|----------|
| 1 | `01-hover-english.png` | 时间线上悬停英语单词，气泡显示中文释义 |
| 2 | `02-save-vocab.png` | 点击单词后出现「已收藏」状态（★）或底部「再点取消」 |
| 3 | `03-line-ja-or-ko.png` | 日语或韩语整行翻译气泡（设置切到日/韩或自动） |
| 4 | `04-popup-vocab.png` | 扩展弹窗：生词本列表 + 实时释义 |
| 5 | `05-popup-settings.png` | 设置页：取词语言、延迟等 |

可选：在截图上方加简短中文标注条（如「悬停查词」），但勿遮挡关键 UI。

---

## 拍摄步骤简述

1. 使用开发者模式加载 `extension/`  
2. 浏览器窗口调整到合适比例后全页或窗口截图，再裁切到 1280×800  
3. 可用系统截图 + 画图裁切，或 ShareX / Flameshot 等  
4. 检查：无个人隐私、无他人私信、无敏感账号信息
