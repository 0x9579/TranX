# 权限与主机权限说明

供 Chrome 网上应用店审核、隐私问卷与自查使用。  
以 `extension/manifest.json` 为准；若清单变更，请同步更新本文件。

**清单版本参考：** 1.3.2

---

## 1. API 权限（permissions）

### `storage`

| 项 | 说明 |
|----|------|
| **用途** | 持久化用户设置、英语生词本、查词结果缓存 |
| **读写内容** | 设置键值；生词本为「英语词 → 时间戳」；缓存为查词结果 |
| **是否离机上传到开发者服务器** | 否（当前版本无自建后端） |
| **用户可控** | 可清除缓存、删除/清空生词；卸载扩展可移除数据 |
| **若无此权限** | 无法记住设置与生词本，体验严重下降 |

**商店「权限说明」可粘贴：**

```text
使用 storage 权限在本地保存您的偏好设置、英语生词本（仅词形与时间）以及查词缓存，以便关闭浏览器后仍可使用。不会用于广告追踪。
```

## 2. 主机权限（host_permissions）

仅用于扩展**后台脚本**发起的 HTTPS 请求（查词/翻译），不是为了读取你在这些网站上的账号内容。

### `https://dict.youdao.com/*`

| 项 | 说明 |
|----|------|
| **用途** | 查询单词/词条的中文释义（有道词典公开/网页接口） |
| **发送数据** | 用户当前查询的词（或短文本） |
| **用户可见收益** | 英语释义；部分场景辅助查询 |

### `https://api.dictionaryapi.dev/*`

| 项 | 说明 |
|----|------|
| **用途** | 英语词的音标与英文定义补充（Free Dictionary API） |
| **发送数据** | 英语单词 |
| **用户可见收益** | 音标、可选英文释义展示 |

### `https://api.mymemory.translated.net/*`

| 项 | 说明 |
|----|------|
| **用途** | 机器翻译（整行日/韩→中、或词典失败时的兜底） |
| **发送数据** | 待翻译的词或一行文本 |
| **用户可见收益** | 日韩整行中文、查词兜底 |

**商店「远程代码 / 主机权限」可粘贴：**

```text
扩展需要访问词典与翻译服务（有道、Dictionary API、MyMemory），以便在您悬停或查询时返回中文释义或译文。仅发送当前查询的单词或一行文本，不用于追踪浏览历史。
```

> 注：v1.3.3 起已移除未使用的 `fanyi.baidu.com` 主机权限。

## 3. 内容脚本匹配（content_scripts.matches）

在下列站点注入脚本与样式（**不是** host_permissions 里的「可跨域 fetch 任意页」，而是页面内运行 UI）：

- `https://x.com/*`
- `https://twitter.com/*`
- `https://www.x.com/*`
- `https://www.twitter.com/*`
- `https://mobile.x.com/*`
- `https://mobile.twitter.com/*`

| 项 | 说明 |
|----|------|
| **用途** | 在帖子文本上检测悬停位置、显示释义气泡、处理英语词点击收藏 |
| **读取** | 指针下的页面文本节点（用于取词/取行） |
| **不读取** | 密码框、扩展外站点 |
| **若无匹配** | 无法在 X 上提供任何悬浮功能 |

**单一用途声明可对照：**

```text
内容脚本仅用于在 X/Twitter 页面提供查词/翻译提示与英语生词收藏，不修改信息流排序，不插入广告。
```

## 4. 未申请的权限（有意为之）

本扩展**未**申请例如：

- `tabs` / `history` / `bookmarks` / `downloads`（导出用前端 Blob 下载，通常无需 downloads 权限）  
- `identity` / 用户登录  
- `<all_urls>` 广泛访问  

有利于通过「最小权限」审核。

## 5. 数据披露问卷（常见勾选参考）

以下按**当前实现**建议（提交时以商店最新问卷为准）：

| 问题方向 | 建议回答思路 |
|----------|----------------|
| 是否收集个人身份信息 | 否（不收集姓名邮箱等；除非你另建账号系统） |
| 是否收集健康/财务等敏感信息 | 否 |
| 是否出售数据 | 否 |
| 是否用于第三方广告 | 否 |
| 用户数据是否离开扩展/设备 | 查词时词句会发往词典/翻译服务；生词本本地存储 |
| 是否远程代码 | 否（逻辑均在扩展包内；仅请求数据 API） |

## 6. 审核话术（简短版）

```text
TranX 在 X/Twitter 上提供悬停查词与可选英语生词本。
使用 storage 保存本地设置与词表；使用内容脚本在帖子文本上显示提示。
使用 host 权限仅向词典/翻译 API 请求当前词或一行文本的释义/译文。
不收集账号密码，不做广告追踪，不执行远程代码。
```
